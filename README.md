# Android 平板雙向 Push-to-talk 翻譯器

這是一個給 Android 手機 / 平板使用的安裝型網頁 App。用 Android Chrome 開啟後，可以加入主畫面，現場使用時像 App 一樣全螢幕操作。

## 功能

- 對方語言選單：越南文、印尼文、泰文、英文
- 左側大按鈕：醫師按住說中文
- 右側大按鈕：外籍勞工按住說母語
- 中間顯示對話紀錄：原文 + 翻譯
- 健檢常用句快捷鍵
- 清除紀錄
- 對話字體大小調整
- 翻譯後自動朗讀

## 使用方式

1. 用 HTTPS 網址或本機 localhost 開啟 `index.html`。
2. Android Chrome 允許麥克風權限。
3. 選擇對方語言。
4. 按住左側或右側大按鈕說話，放開後自動加入對話紀錄。
5. 點選健檢常用句可直接顯示並朗讀翻譯。

## 注意

語音辨識需要瀏覽器支援，建議使用 Android Chrome。自由語音翻譯目前使用線上翻譯服務；健檢快捷句則內建在本機，不依賴翻譯 API。
