# 醫療即時雙向翻譯器 (Gemini Live Edition)

> **🚀 線上立即使用：[https://graffiti2100.github.io/android-ptt-translator/](https://graffiti2100.github.io/android-ptt-translator/)**

這是一個專為醫療現場打造的「**即時雙向語音翻譯 Web App**」。採用最新 **Gemini Live Bidi API** (WebSocket 即時音訊串流) 技術，提供不間斷、免按鍵的流暢雙向溝通體驗。
建議使用 Android Chrome 開啟後，點選「加到主畫面」，即可像原生 App 一樣全螢幕操作。

## 🌟 核心功能

- **即時雙向語音串流 (Live API)**：開啟後無需反覆按鍵，系統會自動聆聽、辨識語言並即時語音回覆。
- **神仙通道自動探索**：自動驗證您的 API Key，並智慧尋找當下具備 `bidiGenerateContent` 權限的專屬模型通道。
- **免持模式 (Open Mic)**：單一按鈕啟動，紅燈常亮時隨時開口，翻譯結果即時雙語顯示。
- **雙模型備援架構**：語音串流使用高階 Live 模型，文字快捷句使用輕量級模型節省額度。
- **健檢常用句快捷鍵**：內建門診與體檢常見問答，點擊直接發音。
- **PWA 支援**：支援離線快取，可將網頁安裝至手機桌面，隨點即用。

## 📱 使用方式

1. 使用手機瀏覽器開啟上方的線上網址。
2. 點擊齒輪圖示 (⚙️)，輸入並儲存您的 **Gemini API Key**。
3. 選擇對方語言（印尼文、越南文、泰文、英文）。
4. 按下紅色的 **「啟動即時雙向翻譯」**。
5. 允許瀏覽器使用麥克風權限。
6. 將手機放著，醫病雙方即可直接對話，享受如同真人翻譯在場的體驗！

## ⚠️ 注意事項

- 本系統強制需要 HTTPS 環境才能開啟麥克風，因此請務必透過 GitHub Pages 或具備 SSL 憑證的伺服器存取。
- Live API 處於測試階段，若連線遭拒 (1007/1008)，請確認您的 API Key 是全新申請且帳號具備 Gemini 體驗資格。
